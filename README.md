# Marble Smash 🐤

Tek dosyalık HTML5 (Canvas 2D) hyper-casual oyun — topunla voxel hedefleri parçala,
misketler döner raya dizilsin ve renk eşleşen kutulara (3/3) sıralansın.

**Oyna:** https://orhunbaykanspyke.github.io/marble-cannon-web/

- 3 level: civciv, kilit+anahtar mekanikli smile, hediye kutusu
- Web Audio synth ses efektleri, haptik geri bildirim
- Bağımlılık yok; `index.html` tarayıcıda doğrudan da açılır
- `?demo` otomatik oynatır, `?debug` FPS gösterir
